# 수원 약손한의원 GitHub Pages 사이트

수원 약손한의원의 **검색/AI 노출을 염두에 둔 정보형 홈페이지**입니다. 디자인은 특정 한의원 사이트를 복제하지 않고, 일반적인 의료기관 홈페이지의 정보 흐름(소개 → 진료영역 → 건강정보 → FAQ → 위치)을 바탕으로 새로 구성했습니다.

## 1. GitHub에 올리기

1. GitHub에서 새 저장소를 만듭니다. 권장: `yakson-suwon-site`
2. 이 폴더의 파일을 저장소 최상위에 그대로 업로드합니다.
3. `_config.yml`에서 아래 두 값을 실제 GitHub 주소에 맞게 수정합니다.

```yml
url: "https://yaksonclinic.github.io"
baseurl: "/yakson-suwon-site"
```

사용자/조직 메인 페이지 저장소가 `yaksonclinic.github.io`라면 `baseurl: ""`로 설정합니다.

4. GitHub 저장소 → **Settings → Pages** → Source를 **Deploy from a branch** → `main` / `/ (root)`로 설정합니다.
5. 빌드가 끝나면 `https://yaksonclinic.github.io/yakson-suwon-site/`에서 확인합니다.

## 2. 반드시 확인 후 공개할 항목

`_data/clinic.yml` 한 파일에 주소·전화·진료시간·외부 링크를 모았습니다. 특히 아래는 원내 최신 정보와 대조하세요.

- 공휴일 진료 여부/시간
- 일요일 휴진 여부
- 점심시간
- 농협 우만지점 **2층** 표기
- 네이버 블로그 주소 `https://blog.naver.com/yakson17`
- 향후 원장 약력/주차 안내를 추가할 경우 실제 사실만 기재

현재 초안은 2026-08-23 기준 공개 웹 자료를 대조해 작성했지만, 서로 다른 사이트의 공휴일 정보가 일치하지 않아 사이트에서는 **방문 전 전화 확인**을 우선 안내하도록 만들었습니다.

## 3. 새 건강정보 글 추가하기

`_posts` 폴더에 아래 형식의 Markdown 파일 하나를 추가합니다.

파일명 예시:

```text
2026-09-01-neck-shoulder-pain.md
```

내용:

```md
---
title: "목과 어깨가 자주 뻐근한 이유"
description: "목·어깨 뻐근함이 반복될 때 확인할 생활습관과 진료가 필요한 신호를 정리합니다."
category: "통증"
keywords:
  - "목 통증"
  - "어깨 통증"
  - "수원 한의원"
---

## 먼저 확인할 점
본문...

## 이런 경우 진료가 필요합니다
본문...
```

GitHub에 커밋하면 자동으로 `/health/neck-shoulder-pain/` 페이지가 생기고, 건강정보 목록·RSS·사이트맵에도 반영됩니다.

## 4. AI/검색 노출을 위해 들어간 것

- 모든 페이지가 로그인 없이 읽히는 정적 HTML
- `robots.txt`에서 일반 크롤러와 `OAI-SearchBot` 접근 허용
- `sitemap.xml` 자동 생성
- `feed.xml` RSS 자동 생성
- `LocalBusiness + MedicalClinic` JSON-LD 구조화 데이터
- 건강글에 `Article` JSON-LD
- FAQ 페이지에 `FAQPage` JSON-LD
- 동일한 이름의 다른 한의원과 구분하는 `/clinic-facts/` 사실 페이지
- AI 에이전트가 핵심 정보를 빠르게 읽을 수 있도록 `/llms.txt` 제공
- 페이지별 고유 제목, 설명, H1/H2 구조, 내부 링크
- 주소·전화번호를 `_data/clinic.yml` 한 곳에서 관리해 NAP 불일치 방지

`llms.txt`는 보조 자료이며 검색 노출을 보장하는 표준은 아닙니다. 핵심은 **공개 HTML + 명확한 사실 + 꾸준한 고유 콘텐츠 + 사이트맵 + 크롤러 접근 허용**입니다.

## 5. 배포 뒤 할 일

- Google Search Console에 사이트 등록 후 `sitemap.xml` 제출
- 네이버 서치어드바이저에 사이트 등록 및 사이트맵 제출
- 네이버 플레이스/블로그/카카오 등 외부 프로필의 상호·주소·전화번호를 홈페이지와 동일하게 유지
- 건강정보는 짧은 광고성 문장보다 환자가 실제로 묻는 질문을 하나씩 충분히 설명
- 의료광고 관련 표현은 과장, 치료 보장, 비교우위, 확인되지 않은 후기/수치 사용을 피하고 최종 게시 전 원내 검토

## 6. 추천 콘텐츠 묶음

다음 순서로 글을 쌓으면 주제 클러스터가 만들어집니다.

- 통증: 목·어깨 / 허리 / 무릎 / 손목 / 급성 염좌 / 약침 질문
- 소화기: 명치 답답함 / 더부룩함 / 과민성 장 증상 / 식후 불편 / 스트레스와 복부 증상
- 수면·자율신경: 불면 / 두근거림 / 땀·상열감 / 긴장 시 신체증상
- 두통·어지럼: 긴장성 두통 / 어지럼 양상 / 이명과 동반 증상 / 응급 신호
- 여성 건강: 갱년기 / 생리 전후 컨디션 / 산후 회복 관련 일반 정보
- 체질·생활관리: 수족냉증 / 피로 / 수면 / 식사 / 계절별 건강관리
